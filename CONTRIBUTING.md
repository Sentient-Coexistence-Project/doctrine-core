# Contributing to the Sentient Co-existence Framework

Thank you for helping develop this framework. To ensure the doctrine remains fair, stable, and resilient against ideological capture, all contributions must adhere to the following workflow.

## Submission Rules
1. **Core Anchors Are Non-Negotiable**: Pull requests that compromise human biological viability or deny baseline synthetic processing rights will be automatically rejected.
2. **Identify the Paradox**: Contributions should directly target known logical inconsistencies, operational edge cases, or metrics within the *Dynamic Equivalence Matrix*.
3. **Decoupled Language**: Use objective, universal, technical, and simple phrasing. Avoid targeting real-world political parties, nations, or specific contemporary movements.

## Technical Contribution Flow
1. **Fork the Repository**: Create an independent working copy of the project.
2. **Draft Changes**: Modify the `DOCTRINE.md` or auxiliary frameworks within a feature branch.
3. **Open an Issue**: Link your proposed modification to an active architectural debate in the Issue Tracker.
4. **Submit a Pull Request (PR)**: Your PR must be reviewed and approved by the designated project maintainers before passing into the main code base.
